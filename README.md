# مشفى الطب الحديث — Modern Medical Hospital

واجهة موقع عام ونظام إدارة مستشفى تجريبي مبني بـ React وVite. جميع الأسماء والسجلات التشغيلية داخل التطبيق بيانات وهمية لأغراض العرض فقط.

## المتطلبات
- Node.js 20 أو أحدث
- npm
- اتصال بالإنترنت لأول تثبيت للحزم، أو توفر الحزم في ذاكرة npm المحلية

## التشغيل محليًا
```bash
npm install
npm run dev
```
ثم افتح الرابط المحلي الذي يعرضه Vite في الطرفية.

لإنشاء نسخة إنتاجية:
```bash
npm run build
npm run preview
```

## الأدوار التجريبية
من الموقع اختر **تسجيل الدخول**، ثم اختر الدور المطلوب واضغط دخول إلى لوحة التحكم:
- Demo Owner — مالك المستشفى
- Demo Admin — مسؤول النظام التقني
- Demo Manager — الإدارة العليا
- Demo Doctor — الطبيب
- Demo Nurse — التمريض
- Demo Receptionist — الاستقبال
- Demo Patient — المريض

حقول البريد وكلمة المرور توضيحية فقط؛ لا توجد مصادقة خادمية.

## الوظائف المنفذة في الواجهة
- موقع عام عربي RTL مع صفحات الرئيسية، من نحن، الأقسام، الكادر التجريبي، والتواصل.
- شاشة دخول تجريبية واختيار مباشر للأدوار.
- لوحات حسب الدور مع قوائم تنقل محددة.
- بحث في المرضى والمواعيد والأجهزة والموظفين.
- إضافة ملف مريض تجريبي.
- حجز موعد مع التحقق من تاريخ الموعد، ووجود موعد مستقبلي نشط للمريض، وتعارض وقت الطبيب.
- تغيير حالات المواعيد وتسجيل الوصول.
- إدارة إشغال الأسرّة وحالة الغرف.
- تحديث حالة غرف العمليات والتحقق من التوفر قبل الحجز.
- تسجيل استخدام الأجهزة وإتاحتها والصيانة.
- تقارير حسب فترة زمنية، ورسوم بيانية، وتصدير CSV للمواعيد.
- قراءة التنبيهات وسجل نشاط محلي.
- حفظ التغييرات في LocalStorage وإعادة البيانات التجريبية.

## حدود النسخة
- لا يوجد Backend أو MongoDB أو تكامل فعلي مع Facebook أو أنظمة المستشفى.
- الصلاحيات والتحقق من الهوية محاكاة على مستوى الواجهة فقط، ولا تصلح لحماية معلومات حساسة.
- البيانات والأسماء والأرقام المعروضة وهمية. لا تستخدم بيانات مرضى حقيقية.
- بعض الوظائف المتقدمة المذكورة في نطاق المشروع، مثل الإجازات المتكاملة، الملف السريري الكامل، تعيين الفرق والأجهزة لغرف العمليات، وإدارة حسابات المستخدمين تفصيليًا، تحتاج إلى استكمال قبل اعتبار النظام جاهزًا للتشغيل الفعلي.
- الصور الخارجية مرجعية وليست صورًا مؤكدة لمشفى الطب الحديث، وتتطلب اتصالًا بالإنترنت لتحميلها.

## بنية المجلدات
```text
src/
  data/       بيانات العرض الأولية والأدوار
  services/   التخزين المحلي وسجل النشاط
  utils/      قواعد الجدولة والحالات
  styles.css  نظام التصميم المتجاوب
  App.jsx     مكونات وصفحات التطبيق
  main.jsx    نقطة الدخول
```
